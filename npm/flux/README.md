# @upskale/flux

The `flux` CLI: check, build and serve [Flux](https://flux.upskalelabs.dev)
projects. One `.flx` source compiles to a React website and a Flutter app.

```sh
npm create @upskale/flux@latest my-app
cd my-app
npx flux dev
```

Or add it to a project: `npm install -D @upskale/flux`, then `npx flux check`.

npm installs the native build for your machine (Windows, macOS and Linux, x64
and arm64). There's nothing to compile, and you don't need Go.
